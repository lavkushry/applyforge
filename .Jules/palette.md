## 2024-04-06 - Missing focus-visible on base Button component\n**Learning:** The base `Button` component in `apps/web/components/ui/button.tsx` lacked explicit `focus-visible` styles, meaning keyboard navigation lacked clear visual indicators across the entire application. Custom interactive card elements (`<button>`) also lacked focus states.\n**Action:** Add `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-cyan-400 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-950` to the generic `Button` component and any custom interactive elements to ensure consistent keyboard accessibility.
