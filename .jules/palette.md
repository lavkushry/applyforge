## 2024-05-15 - Forms missing label bindings and error descriptions
**Learning:** I found that the `AuthForm` (and likely other forms in `apps/web/components/forms/`) are missing fundamental accessibility attributes. Specifically, inputs lack `id` attributes that correspond to `<label htmlFor="...">`, breaking screen reader associations. Additionally, validation errors do not have `role="alert"`, and inputs lack `aria-describedby` pointing to those error messages, meaning visually impaired users may not be notified when validation fails.
**Action:** Always ensure that form inputs have a unique `id` that matches their `<label>`'s `htmlFor` attribute. When adding validation feedback, add `role="alert"` to the error message element, and link it to the input using `aria-describedby="[error-id]"`. Set `aria-invalid={true}` on the input when an error exists.
