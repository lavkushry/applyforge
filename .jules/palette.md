## 2024-05-08 - Missing Form Accessibility Bindings
**Learning:** React Hook Form usage in the project often relies heavily on surrounding `<label>` wrappers or purely visual validation error text, omitting explicit programmatic links (`htmlFor`/`id` bindings connecting labels to inputs, and missing `aria-describedby` linking inputs to validation errors equipped with `role='alert'`). This makes the forms less accessible to screen readers, especially regarding context and error notification.
**Action:** When implementing or fixing forms, always explicitly bind `<label>` elements to `<input>` or custom components using `htmlFor` and `id`. Additionally, dynamic validation messages should use `role="alert"` and have an explicit `id` referenced by the input's `aria-describedby` attribute to announce errors to assistive technologies appropriately.
