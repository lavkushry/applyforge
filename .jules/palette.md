## 2025-01-20 - Missing Form Label Bindings in Components
**Learning:** Many form components within `apps/web/components/forms/` (e.g., `settings-form.tsx`, `profile-form.tsx`, `job-create-form.tsx`, `role-create-form.tsx`) were using generic `<label>` and `<input>`/`<select>` pairs without explicitly associating them via `htmlFor` and `id` attributes. This breaks accessibility for screen reader users because the label text is not read when the input receives focus.
**Action:** When creating or modifying form components, always ensure that each `<label>` has an `htmlFor` attribute that exactly matches the `id` attribute of its corresponding input element. Similarly, use `aria-label` or `aria-describedby` when labels are implicitly defined by surrounding elements or context (like the "Disconnect" button in loops).
