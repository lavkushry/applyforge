## 2024-05-15 - Missing Form Label Bindings and Error Associations
**Learning:** Across the `apps/web/components/forms/` directory, forms rely on structural proximity for visual labeling (e.g., `<label>` followed by `<Input>`) rather than explicit `htmlFor` and `id` bindings. Additionally, validation errors are conditionally rendered without `aria-describedby` linking the input to the error message or `aria-invalid` marking the field's state. This makes form navigation and error discovery difficult for screen reader users.
**Action:** When working on forms, proactively use `useId()` from React to generate unique stable IDs. Bind labels using `htmlFor`, and link input error states using `aria-invalid={!!errors.field}` and `aria-describedby` pointing to the error element's `id` equipped with `role="alert"`.
