## 2024-06-12 - Consolidate independent metrics into single queries
**Learning:** Dashboard-style endpoints (like `wizard_summary`) that perform multiple independent database checks (e.g., `count()` or `exists()`) across different tables can trigger N+1 query patterns. These can be optimized in FastAPI/SQLAlchemy by wrapping each check in `scalar_subquery()` within a unified `select()`.
**Action:** Always combine multiple independent counts and existence checks into a single database round-trip for dashboard-style endpoints. Note: to avoid AttributeError, wrap `exists()` in a secondary select (e.g., `select(select(Model.id).where(...).exists()).scalar_subquery()`), and rely on standard truthy evaluation for JSON/Array column subqueries instead of strict `is not None` checks.
