## 2024-05-24 - Optimize Wizard Summary Dashboard Queries
**Learning:** Using multiple independent `.first()`, `.count()`, and `.exists()` queries on the SQLAlchemy ORM for a dashboard view causes N+1 like latency by firing 6+ sequential database round-trips. When consolidating these queries, `func.json_array_length()` or dictionary key checks should not be pushed to the database for JSONB columns, as they can cause crashes on NULL or scalar values. Instead, the raw columns should be fetched via `scalar_subquery()` and validated safely in Python.
**Action:** Always consolidate multiple independent dashboard counts and existence checks into a single database round-trip by wrapping them in `scalar_subquery()` within a unified `select()` statement, and append `.limit(1)` when replacing `.first()` queries. Ensure each scalar subquery returns exactly one column.
