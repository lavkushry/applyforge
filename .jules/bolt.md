## 2023-10-25 - Consolidate Multiple Queries in Dashboard Endpoints
**Learning:** When optimizing dashboard-style endpoints (e.g., `wizard_summary`), executing multiple independent `first()` and `count()` queries causes unnecessary database round-trips (N+1 query-like behavior). Using dialect-specific SQL functions or keeping validation in the database can cause crashes or errors.
**Action:** Consolidate multiple independent counts and existence checks into a single database round-trip by wrapping `func.count()` and `exists()` clauses in `scalar_subquery()` calls within a unified SQLAlchemy `select()` statement. Wrap `exists()` in a secondary select (e.g., `select(select(Model.id).where(...).exists()).scalar_subquery()`), append `.limit(1)` when replacing `.first()` queries, and ensure each scalar subquery returns exactly one column. Extract JSON/Array columns safely via `scalar_subquery()` and evaluate truthiness purely in Python.
