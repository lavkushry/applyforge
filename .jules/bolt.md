## 2025-05-25 - Ingestion Batching and Caching
**Learning:** Ingestion services in `apps/api` (`role_ingestion.py`, `company_ingestion.py`) loop over fetched payloads and query the database for duplicate `Job` records by `dedupe_key` one by one, resulting in an N+1 query problem. Also, `company_ingestion.py` redundantly queried the DB to resolve the company when the payload company name often exactly matches the existing target company in memory.
**Action:** Use a two-pass pattern to first gather all `dedupe_key`s and fetch existing records in a single batch query (`.in_()`), updating the local lookup dict inside the loop after any `db.add()`/`db.flush()` to properly handle duplicates within the same run. Bypass the DB query for company resolution when the payload's company name trivially matches the target company name.
