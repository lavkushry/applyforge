## 2025-06-20 - Consolidate Multiple Independent Queries Using scalar_subquery()
**Learning:** When building dashboard-style endpoints with numerous independent aggregate counts and boolean existence checks across unrelated tables, making individual db.query() calls for each introduces significant latency through N round-trips. Grouping multiple simple queries together doesn't work out of the box because exists() on its own causes an AttributeError when wrapped in select(), and unconstrained subqueries might return multiple rows.
**Action:** Instead of multiple round-trips or fragile database-side logic, consolidate these counts and existence checks into a single query by wrapping func.count() and exists() in scalar_subquery() calls within a unified SQLAlchemy select(). Always wrap exists() in a secondary select (e.g., select(select(Model.id).where(...).exists()).scalar_subquery()), and append .limit(1) to any scalar subquery retrieving individual fields.
