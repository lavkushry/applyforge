## 2024-06-25 - Path Traversal via Backslash on POSIX
**Vulnerability:** The application was vulnerable to path traversal because it used `Path(filename).name` (and `.suffix`) to process user-uploaded filenames directly. On POSIX systems, Python's `pathlib.Path` treats backslashes (`\`) as valid filename characters, not directory separators. This allowed an attacker to upload files with names like `evil\..\..\etc\passwd`, which would bypass simple directory validation and result in path traversal when the system interpreted the backslashes as path components later.
**Learning:** Using `pathlib.Path().name` is not sufficient for sanitizing user-provided filenames on POSIX systems if the filenames might contain backslashes intended for path traversal. Backslashes are not stripped or interpreted as separators.
**Prevention:** Always manually normalize backslashes to forward slashes (e.g., `filename.replace(chr(92), "/")`) before parsing filenames with `Path` when dealing with user-uploaded files, or ensure robust filename sanitization that rejects unauthorized characters.
