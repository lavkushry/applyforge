## 2024-05-24 - Path Traversal via Backslashes in User Uploads
**Vulnerability:** The `save_upload` function used `Path(filename).name` to extract the base name of user-uploaded files. While safe on Windows, on POSIX systems (Linux/macOS), backslashes (`\`) are treated as valid filename characters, not directory separators. A malicious payload like `..\..\etc\passwd` would bypass the extraction and lead to arbitrary file writes when prepended with the upload directory path (e.g. creating files with backslashes in their names or even traversal if not careful).
**Learning:** `Path(filename).name` is platform-dependent and fails to handle Windows-style path separators on POSIX systems. Since FastAPI/Starlette passes the raw filename provided by the client, an attacker can specify cross-platform traversal payloads.
**Prevention:** Always use a custom sanitization function for uploaded filenames that explicitly replaces backslashes with forward slashes before applying `Path.name`, strictly enforces an alphanumeric/dot/dash allowlist, and strips leading dots to prevent hidden files or `..` bypasses.
