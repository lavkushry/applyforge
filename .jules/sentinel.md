## 2024-05-24 - Path Traversal in File Uploads
**Vulnerability:** The `save_upload` function relied solely on `Path(filename).name` to extract the base name of user-uploaded files. On POSIX-based servers, this standard library function fails to strip out backslashes (`\`), meaning an attacker using a Windows-style path (e.g., `..\\..\\..\\etc\\passwd`) could bypass the check and traverse the filesystem when the file is saved.
**Learning:** `Path().name` behavior is OS-dependent. When running Python on Linux/macOS, it treats `\` as a regular character in a filename, not a directory separator. You cannot trust standard path utilities to handle paths constructed maliciously from a different OS.
**Prevention:** Always manually normalize backslashes to forward slashes before extracting the base name (e.g., `filename.replace("\\", "/")`) and, crucially, apply a regex allowlist (`r"[^a-zA-Z0-9.\-_]"`) to explicitly sanitize the filename, removing any potentially dangerous characters or sequences entirely.
