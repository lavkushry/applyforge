## 2026-06-09 - Path Traversal via Backslash Evasion in Python Pathlib
**Vulnerability:** Python's `Path(filename).name` does not treat backslashes (`\`) as directory separators on POSIX systems. This allowed attackers to submit filenames like `..\..\etc\passwd` or `foo\bar.pdf`, bypassing suffix checks and potentially allowing writing files outside of expected directories if the `.name` attribute was relied upon for sanitization.
**Learning:** On POSIX systems, `pathlib` assumes paths use forward slashes. Backslashes are treated as literal valid filename characters, allowing attackers to construct paths that appear completely flat to `pathlib` but are evaluated as traversals by underlying C libraries or when moved to a Windows system.
**Prevention:** Always manually normalize backslashes to forward slashes (e.g., `filename.replace("\\", "/")`) before passing user-controlled file paths to `pathlib.Path` or `os.path.basename` to ensure cross-platform path safety and proper extraction of extensions and filenames.
