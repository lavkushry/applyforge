## 2024-05-16 - Path Traversal Vulnerability via Backslash Evasion on POSIX Systems
**Vulnerability:** In file upload handling (`apps/api/app/services/files.py`), the codebase used `Path(filename).name` to extract a safe filename. On POSIX systems (Linux/macOS), the Python `pathlib.Path` module does not treat backslashes (`\`) as path separators. Therefore, a maliciously crafted filename like `..\..\..\malicious.exe` is interpreted as a single, flat filename. When combined with a storage directory, this results in a path traversal vulnerability.
**Learning:** `Path(filename).name` is insufficient to protect against path traversal attacks if the host OS is POSIX, because attackers can use Windows-style backslashes to bypass the check.
**Prevention:** Always normalize filenames by replacing backslashes with forward slashes (`filename.replace("\\", "/")`) before passing them to `Path`. Additionally, apply a strict regex allowlist (e.g., `re.sub(r"[^a-zA-Z0-9.\-_]", "_", base_name)`) to enforce safe characters, rather than relying solely on path extraction.
