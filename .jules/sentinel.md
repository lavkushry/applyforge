## 2024-05-18 - Path Traversal in File Uploads using pathlib
**Vulnerability:** The codebase processed user-uploaded filenames using `Path(filename).name` and `Path(filename).suffix` in `apps/api/app/services/files.py`. This is vulnerable to path traversal on POSIX systems when an attacker uses backslashes (e.g., `..\..\etc\passwd`).
**Learning:** In Python, `pathlib.Path` behaves according to the underlying operating system. On POSIX systems, `Path` does not consider backslashes as path separators, but rather as valid filename characters. Thus, `Path("..\\..\\etc\\passwd").name` returns the whole string instead of stripping directories, allowing files to be saved outside the intended storage directory if concatenated to a base path.
**Prevention:** Always manually normalize backslashes to forward slashes (e.g., `filename.replace("\\", "/")`) before passing user-supplied filenames to `Path()`, or use safer utilities like `werkzeug.utils.secure_filename` to ensure pure filenames are properly sanitized across all platforms.
