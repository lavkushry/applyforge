## 2024-03-24 - Path Traversal via Windows File Paths on POSIX Systems
**Vulnerability:** User-uploaded filenames were passed to `Path(filename).name` in `apps/api/app/services/files.py` to extract the base name before saving. On POSIX systems, `Path` does not recognize `\` as a directory separator. If a malicious user sends a filename like `..\..\etc\passwd`, `Path(filename).name` returns `..\..\etc\passwd` directly. This allows arbitrary file write access outside of the intended storage directory if not mitigated.
**Learning:** Python's `pathlib.Path` module handles paths differently depending on the operating system it runs on. On Linux/macOS, it uses `PosixPath`, which only treats `/` as a separator. On Windows, it uses `WindowsPath`, which handles both `/` and `\`. Relying on `Path(filename).name` is unsafe for cross-platform validation.
**Prevention:** Always manually normalize backslashes to forward slashes before extracting the base name. Apply a strict regex allowlist to ensure only safe characters are preserved.
