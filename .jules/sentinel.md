## 2024-05-24 - Path Traversal bypass via Backslash normalization

**Vulnerability:** Path traversal vulnerability due to backslash bypass in filename extraction on POSIX systems. When handling user uploaded files, using `Path(filename).name` alone does not reliably strip out path segments containing backslashes (e.g. `..\..\etc\passwd`) when executed on a POSIX system, because POSIX treats `\` as a valid filename character rather than a directory separator. This leaves the backslashes in the output of `.name`, which might then trigger traversal issues if processed on Windows, or cause other downstream processing errors.
**Learning:** `pathlib.Path` behaves differently depending on the operating system it is running on. On POSIX (Linux/macOS), it interprets filenames using POSIX rules where backslashes are valid filename characters. Therefore, `Path("..\\..\\etc\\passwd").name` evaluates to `..\\..\\etc\\passwd` instead of `passwd`.
**Prevention:** Always manually normalize backslashes to forward slashes (`filename.replace("\\", "/")`) before passing it to `Path` or `os.path` functions when extracting components from user-supplied paths, ensuring consistent extraction regardless of the host OS.
