## 2024-03-24 - File Upload Path Traversal Vulnerability
**Vulnerability:** The `save_upload` function in `apps/api/app/services/files.py` was directly using `Path(filename).name` to extract the filename from user-provided input. While this strips forward slashes (Linux/Mac paths), it fails to sanitize backslashes (Windows paths) like `..\..\..\etc\passwd`, allowing path traversal when the file is saved.
**Learning:** `Path(filename).name` is platform-dependent and insufficient for sanitizing user-provided filenames, especially cross-platform payloads. Furthermore, using user-provided filenames directly without character filtering allows potentially harmful characters to reach the filesystem.
**Prevention:** Implement a dedicated `secure_filename` utility that explicitly handles cross-platform path separators (e.g., replacing `\` with `/`), strips the path components, explicitly whitelists safe characters (alphanumeric, dots, hyphens, underscores), and strips leading dots to prevent hidden files or relative path traversal bypasses. Always use this utility before interacting with the filesystem.
