## 2024-05-18 - Path Traversal in File Uploads
**Vulnerability:** Path traversal possible through `Path(filename).name` and `Path(filename).suffix` by using backslashes on POSIX environments (like Linux/Mac). Backslashes are treated as regular filename characters in POSIX systems, allowing attackers to upload to arbitrary paths if validation fails or is poorly handled, or if it writes to disk.
**Learning:** Python's `pathlib.Path(filename).name` method does not strip backslashes (`\`) on POSIX systems. If the filename is provided by an attacker, `..\..\` is treated as a valid filename instead of directories, but some OS-level save commands might misinterpret it or if used in downstream file paths, might allow directory traversal. Normalizing `\` to `/` ensures backslashes are always treated as path separators and correctly discarded by `.name` or `.suffix`.
**Prevention:** Always normalize backslashes to forward slashes before parsing file names from user uploads on POSIX environments: `Path(filename.replace("\\", "/")).name`.
